01 · DISCOVERY TIME

When does DFS first reach a vertex?

The first time DFS visits a vertex, it gives it the next number. This is its discovery time, disc[u]. It is a timestamp—not a distance.

disc[u] = ++time
Why this matters

The timestamps let us compare how far back toward the DFS root a subtree can reach.

CHECK YOUR UNDERSTANDING

What does the comparison tell us?

In these formulas, u means the parent vertex and v means one of u’s DFS-tree children. The value low[v] belongs to the child’s whole DFS subtree; disc[u] is the time DFS first visited its parent. Assume u is not the DFS root for this comparison.

Equal: the important boundary case.

The subtree can reach u itself, but has no route to an ancestor above u. So u can still be an articulation point. The edge (u,v) is not a bridge because that return route exists.

Articulation point: YES (u)Bridge: NO (u–v)
BEFORE THE FORMULAS

What do the letters mean?

We use u and v as placeholders so one rule can describe every parent–child pair in a DFS tree. They are not special vertices in the example.

u — parent

The vertex DFS was at before it discovered v.

v — child

A vertex first reached by exploring an unvisited neighbour of u.

disc[x]

The first-visit number assigned to vertex x.

low[x]

The smallest discovery number reachable from x’s DFS subtree using tree edges down and at most one back edge to an ancestor.

One more term: an ancestor is a vertex earlier on the current DFS path. A descendant is a vertex reached further down that path.

01 · FOUNDATION

Graph and DFS

A graph has vertices (the points) and edges (the connections). Depth-First Search (DFS) starts at one vertex, follows an unvisited neighbour as far as possible, and backtracks when it has no unvisited neighbour left.

02 · THE NUMBER

Discovery time: disc[x]

When DFS first reaches vertex x, it assigns the next clock number. A smaller number means that vertex was discovered earlier. It does not measure distance or path length.

disc[x] = ++time
03 · THE ALTERNATE ROUTE

Back edge

In an undirected DFS, a back edge connects a vertex to an ancestor that is already on the DFS path. It is not the tree edge to the parent. It gives the subtree another route upward.

04 · THE SUMMARY

Low value: low[x]

Start with disc[x]. Then include discovery times reached by back edges from x or its DFS descendants. The smallest such time is low[x]. When a child finishes, its low value can be passed to its parent.

low[u] = min(disc[u], low of its children, reachable ancestors)
05 · WHY A BCC?

Biconnected component

A biconnected component (BCC) is a maximal group of edges that belongs together without an articulation vertex inside the group: within the component, no single vertex is the only connection holding the rest together. Two BCCs may share an articulation vertex, as the two triangles in our example share C.

A vertex can therefore belong to more than one BCC. The components are groups of edges; they are not necessarily disjoint sets of vertices.

WORKED EXAMPLE · SAME GRAPH AS THE LESSON

Trace the values by hand

Edges are AB, BC, CA, CD, DE and EC. Start DFS at A and visit A → B → C → D → E. The DFS tree edges are AB, BC, CD and DE. The back edges are CA and EC.

1 · Discovery times

disc[A]=1, disc[B]=2, disc[C]=3, disc[D]=4, disc[E]=5

Assign each number the first time DFS reaches that vertex.
2 · Start with each vertex’s own time

low[A]=1, low[B]=2, low[C]=3, low[D]=4, low[E]=5

Before considering back edges or child results, low[x] equals disc[x].
3 · Use the back edges

C–A: low[C] can become 1
E–C: low[E] can become 3

C can reach A (time 1); E can reach C (time 3).
4 · Return from children

low[D]=min(4,3)=3
low[C]=min(3,3,1)=1
low[B]=min(2,1)=1
low[A]=1

Each parent keeps the smallest value reported by its child, as well as any back-edge reach from itself.
5 · Test the child D of C

low[D] ≥ disc[C]
3 ≥ 3 → C is an articulation point

D’s subtree returns to C but cannot reach above C. Removing C separates the two triangles.
6 · Extract the two BCCs

{CD, DE, EC} and {AB, BC, CA}

When the boundary is found, pop the edge stack through the tree edge C–D. The edges popped together form one component.
ALGORITHM · READ THE VARIABLES FIRST

Tarjan’s DFS-based BCC procedure

Here, u is the current vertex and v is one of its neighbours. If v is unvisited, it becomes a DFS child. If v is already visited and is not u’s parent, the edge is a back edge to an ancestor.

DFS(u):
  disc[u] = low[u] = ++time

  for each neighbour v of u:
    if v is unvisited:
      parent[v] = u
      push edge (u, v)
      DFS(v)
      low[u] = min(low[u], low[v])

      if low[v] >= disc[u]:
        if u is not the DFS root:
          mark u as an articulation point
        pop edges through (u, v)  // one BCC

    else if v is not parent[u] and disc[v] < disc[u]:
      low[u] = min(low[u], disc[v])
      push edge (u, v)             // back edge

The DFS root is an articulation point only if it has
more than one DFS-tree child.

Remember: low[v] ≥ disc[u] marks a BCC boundary. For a non-root u, it also makes u an articulation point. A bridge uses the stricter test low[v] > disc[u].
